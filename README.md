# Romantic Proposal Website ❤️ (React)

Multi-page romantic proposal site built with **React + Vite + React Router**.

## Pages

| Route | Page |
|-------|------|
| `/` | Landing hero — “Open My Heart” |
| `/proposal` | Love letter + Yes / No |
| `/celebration` | Happiest-person celebration |

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
